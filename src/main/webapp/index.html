Kendo UI JSON 통합 시스템 데모

이 시스템은 JSON 설정을 기반으로 Kendo UI 컴포넌트(Grid, Chart, Form)를 동적으로 생성합니다. 서블릿과 JSON 통신을 통해 데이터를 관리하고, 폼 양식도 JSON으로 정의할 수 있습니다.

JSON 설정을 통해 Grid를 생성하고, CRUD 작업을 수행할 수 있습니다. 편집 폼도 JSON으로 정의됩니다.

JSON 설정을 통해 다양한 유형의 차트를 생성할 수 있습니다.

JSON 설정을 통해 동적 폼을 생성하고, 유효성 검사를 수행할 수 있습니다.
