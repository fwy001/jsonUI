🎯 시작하기

위 카드를 클릭하거나 "실행하기" 버튼을 눌러 예제를 실행하세요. 서버 설치나 빌드 과정 없이 바로 확인할 수 있습니다!

  • 추천: "완전한 통합 데모"부터 시작하세요
  • 인터넷 연결 필요: Kendo UI를 CDN에서 로드합니다
  • 최신 브라우저 사용: Chrome, Firefox, Edge, Safari 권장

📚 주요 기능

  • Grid: JSON 설정으로 Grid 생성, CRUD 작업, 페이징/정렬/필터링
  • Chart: 다양한 차트 타입을 JSON으로 정의, 동적 데이터 바인딩
  • Form: 필드와 유효성 검사를 JSON으로 설정, 자동 검증
  • 통합 시스템: 모든 컴포넌트를 하나의 대시보드에서 관리

💡 팁

  • 각 예제에서 "JSON 설정 보기" 버튼을 클릭하여 설정 구조를 확인하세요
  • Grid에서 데이터를 추가/수정/삭제하며 CRUD 작업을 체험하세요
  • Form에서 잘못된 데이터를 입력하여 유효성 검사를 테스트하세요
  • 브라우저 개발자 도구(F12)로 코드를 확인할 수 있습니다
