🚀 Kendo UI JSON 통합 시스템

JSON 설정만으로 Grid, Chart, Form을 동적으로 생성하는 완전한 데모

✨ 서버 없이 바로 실행 가능한 완전한 예제!

이 페이지는 로컬 환경에서 바로 실행할 수 있습니다. JSON 설정을 통해 Kendo UI 컴포넌트를 생성하는 방법을 확인하세요.

주요 기능

📊 JSON 기반 Grid

컬럼, 데이터소스, 편집 옵션을 JSON으로 정의하여 동적 Grid 생성. CRUD 작업 완벽 지원.

📈 JSON 기반 Chart

다양한 차트 타입(Column, Line, Pie, Bar)을 JSON 설정만으로 생성. 동적 데이터 바인딩.

📝 JSON 기반 Form

필드 정의와 유효성 검사 규칙을 JSON으로 설정. 다양한 입력 위젯 지원.

🔄 실시간 CRUD

Grid에서 데이터 생성, 수정, 삭제를 즉시 수행. 로컬 데이터로 완전한 작동.

✅ 자동 유효성 검사

Form 필드의 유효성 검사를 JSON 규칙으로 정의. 자동 에러 메시지 표시.

🎨 완전한 커스터마이징

모든 UI 요소를 JSON 설정으로 제어. 코드 변경 없이 설정만으로 조정.

사용 방법

1단계: 상단 탭을 클릭하여 각 컴포넌트 예제를 확인하세요.

2단계: Grid 탭에서 데이터 추가/수정/삭제를 시도해보세요.

3단계: Form 탭에서 유효성 검사를 테스트해보세요.

4단계: 통합 대시보드에서 모든 기능을 한눈에 확인하세요.
